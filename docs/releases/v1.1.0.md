# rustyAC v1.1.0

The first release with **Custom Shaders Patch (CSP)** support: a switch, and the cars and tracks
that only need CSP's extended data files now load.

## What's in it

- **`--csp`** (or `[CSP] ENABLED=1` in `cfg\rustyac.ini`) turns on CSP mode. It is off by default,
  and with it off rustyAC is the same bit-exact Assetto Corsa 1.16 as v1.0.1.
- With `--csp`, **15 more cars** load (the ten BDC Street v4 cars, four RSS formula cars and the VRC
  Formula Lithium 2023) and **6 more track layouts** (the `*_fa_2026` layouts of Barcelona, Red Bull
  Ring, Silverstone, Montreal, Monza and Spa). Their `extended-N` values are read exactly as CSP
  0.3.2-preview2 reads them, and CSP's own data sections are kept for later releases.
- Cars that use CSP's COSMIC suspension, and cars whose files are encrypted for CSP by their maker,
  are refused with a clear reason.
- Without `--csp`, cars marked as made for CSP are now refused as plain Assetto Corsa refuses them
  (before, rustyAC loaded the BDC and RSS cars anyway).

## How it's proven

Each of these 15 cars and 3 plain ones is compared, word by word, with the car
the game builds with CSP 0.3.2 running inside the proof tool: every difference CSP makes is one rustyAC's
CSP mode makes too, or memory the physics never uses. Each car then drives against the game's own
code bit for bit, and the six layouts' sound values match CSP's. The details are in
[docs/csp/port_c3.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.0/docs/csp/port_c3.md).

## Known gaps

CSP mode is only the start: CSP's extended physics, its renderer, Lua apps and COSMIC suspension come
in later releases ([docs/csp/plan.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.0/docs/csp/plan.md)).
The rest is as in v1.0.0 ([docs/port/leftovers.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.0/docs/port/leftovers.md)).
