# rustyAC v1.0.0

rustyAC 1.0 is a complete rewrite of **Assetto Corsa 1.16** (`acs.exe`, Kunos Simulazioni, 2014) in
Rust that behaves **bit for bit** like the original. It plays on Windows with your own copy of
Assetto Corsa and in the browser at [rustyac.com/play](https://rustyac.com/play).

## What's in it

- **Physics:** tyres, suspension, drivetrain, aero, electronics (TC, ABS, ERS/KERS, DRS) and
  damage, with ODE 0.13.1 ported for collisions. 119 of the 123 cars and 44 track layouts
  load (the other 4 cars need Custom Shaders Patch).
- **Sound:** AC's own FMOD sound banks for every car.
- **Renderer:** AC's Direct3D 11 renderer with its own shaders, at every video setting, and YEBIS
  post-processing: every filter AC ships, tone mapping, eye adaptation, glare, light shafts,
  depth of field and heat shimmer.
- **Racing:** AI drivers, sessions, flags, penalties, pit stops and pit crew, results, replays
  (your real `.acreplay` files) and the ghost car.
- **The game's UI:** HUD, menus, setup editor, pit strategy, telemetry and the player apps, plus
  AC's Python app API, so Python apps from your install run.
- **AC's launcher**, with Kunos' theme from your install: car, track and session pick, online
  server list, replays, personal bests, special events and career.
- **Online:** joins real Assetto Corsa servers (`acServer`).
- **Game modes:** practice, quick race, race weekend, hotlap, Time Attack, Drift, Drag Race,
  special events and career.
- **Cameras and hardware:** every camera, triple screens, VR (OpenVR and Oculus), TrackIR, force
  feedback and Steam achievements (off by default).
- **Browser build:** the same physics in WebAssembly, AC's launcher, AC's renderer on WebGPU, the
  HUD, menus and apps, AC's sound through FMOD's HTML5 build, AI races and multiplayer through a
  WebSocket gateway. Each release has a `-web.zip` to host yourself
  ([docs/web.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.0.0/docs/web.md)).

## How it's proven

Every part is ported from the game's code and then compared with the game itself:

- **Oracles** load the original `acs.exe` into the same process and run its own functions next to
  the port, comparing every value bit for bit: physics, AI, referee, pit stops, replays, game modes.
- **Renderer and UI:** every Direct3D 11 call and every pixel (on Microsoft's WARP software
  renderer) is compared frame by frame with the game's.
- **Sound:** every FMOD call is logged and compared.
- **Online:** network traffic is compared message by message with the original client.
- **Launcher:** a .NET harness runs the original launcher's code and compares every answer and
  every file it writes.

The full proof run on the release candidate: **2,389 cases in 14 areas, every one IDENTICAL**, with no
errors, no skips and no vanished cases, in 6 h 26 min (528 of the cases are the YEBIS sweep
of all ten filters). Each part's proof is written up in
[docs/port/](https://github.com/thesupersupersigma/rustyAC/tree/v1.0.0/docs/port).

## What you need

- Windows 10 or 11, 64-bit, with Direct3D 11.
- **Your own Assetto Corsa 1.16** (the Steam version). rustyAC finds it in your Steam libraries, or
  set `AC_ROOT`. It reads the cars, tracks, sounds and shaders from there and never writes into
  the game's folder.
- rustyAC ships **none** of Kunos Simulazioni's, Silicon Studio's (YEBIS) or Firelight
  Technologies' (FMOD) files: the zip holds only rustyAC's own two programs and its text files.

To play: unzip `rustyAC-v1.0.0-windows-x64.zip` somewhere you can write to (not `Program Files`) and
run `rustyac-launcher.exe`. `HOW_TO_RUN.txt` in the zip has the rest.

## Known gaps

They are rare, and each one is listed with its size and plan in
[docs/port/leftovers.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.0.0/docs/port/leftovers.md).

- **Desktop:** the airy disc of the b&w and sepia filters (only with depth of field and a replay
  camera zoomed to about 1°) and custom filters' keys no shipped filter uses; a few glare sizes and
  the heat shimmer in VR skip post-processing for that frame; the Friends Leaderboard; Start
  Benchmark; a few launcher and online details.
- **Browser:** no post-processing; some settings files are not saved on exit; F5's free camera;
  AC's two sound plug-ins and track sound occluders; font hinting and CJK fonts.
- **Not supported:** Custom Shaders Patch (CSP). Cars that need it don't load, and cars drive as
  in vanilla Assetto Corsa. AC's showroom (`acShowroom.exe`) is not ported: use the one in your install.

## Where rustyAC differs on purpose

It never writes into the game's folder or your Documents, and it does something sane where the
game crashes, loops or reads memory it never set. All of it is listed in
[docs/port/differences.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.0.0/docs/port/differences.md).

## What's next

Fixes for the known gaps come in 1.0.x releases. Next is **CSP** support (Custom Shaders Patch
cars, tracks and physics), then **Enhanced**: the same game with upgraded physics.
