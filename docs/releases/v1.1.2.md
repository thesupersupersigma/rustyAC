# rustyAC v1.1.2

Browser fixes: the page now says when and why Full mode falls back to the debug view.

## What's in it

- **Full mode's fallback is shown** ([docs/web_fixes.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.2/docs/web_fixes.md), W2):
  when Full mode was asked for and the debug view draws (no WebGPU, a shader the install lacks such
  as a Custom Shaders Patch track's, an error), a banner on the page says why, and AC's launcher
  shows the same line when you come back to it.
- **The pack marks what Full mode cannot draw**: `web_pack` lists the shaders a car's or track's
  models need that the install lacks (`missing_shaders` in the manifest); the page labels those
  items "[debug view only]" and warns before the drive. Nothing is refused.
- No more `Cannot resume a closed AudioContext` error after leaving a drive; the browser's notes no
  longer claim YEBIS and Direct3D post-processing; the page has an icon (`favicon.svg`, new in the
  web zip).
