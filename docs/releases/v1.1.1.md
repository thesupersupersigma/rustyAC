# rustyAC v1.1.1

Browser fixes, a reference for every command-line flag, and CSP's air density.

## What's in it

- **The browser build** ([docs/web_fixes.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.1/docs/web_fixes.md)):
  pressing Escape to go back to the launcher no longer hangs the page; reloading the page works
  again; two leaks are gone (FMOD's bank files and the GPU device are freed after each drive); the
  Full renderer is about 40 % faster (33.6 to 47.8 frames/s on Low, 32.2 to 45.9 on High here), with
  the same pictures byte for byte.
- **[docs/flags.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.1/docs/flags.md)**: every
  flag of rustyac.exe and the tools, what it does and its default; `rustyac.exe --help` corrected to
  match.
- A car's short name is read as the game reads it (`car.ini`'s `SHORT_NAME` only from `[HEADER] VERSION` 2 up, else
  `SCREEN_NAME`).
- With `--csp`, cars with CSP's extended data get **CSP's air density**, bit-exact against CSP's own
  law running in the proof tool.

## Known gaps

`--csp` physics is still Assetto Corsa's own engine with CSP's data read in, not CSP's own physics
core: that is the next work ([docs/csp/plan.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.1/docs/csp/plan.md)).
The rest is as in v1.1.0.
