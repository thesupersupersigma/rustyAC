# rustyAC v1.1.4

Browser fix: Full mode no longer makes Chrome's GPU process grow by gigabytes while you drive.

## What's in it

- **Full mode's memory** ([docs/web_fixes.md](https://github.com/thesupersupersigma/rustyAC/blob/v1.1.4/docs/web_fixes.md), W4):
  every draw pass made a new buffer for its constants, and Chrome kept a 4 MB upload area for
  each, so its GPU process grew from the first frame of a drive: 8-15 GB within minutes on Spa
  (one test run reached 18.5 GB). The page now writes those bytes into one buffer it keeps;
  the GPU process stays flat, 1.5-2.9 GB on the same drives, and the picture is unchanged.
