rustyAC browser preview

Assetto Corsa's physics, rewritten in Rust and compiled to WebAssembly: the same numbers, bit for bit, as the desktop build. A small picture, keyboard and gamepad. No sound, and not AC's own look: this is a preview.

1. Content

The folder is the one with content and system in it (...\steamapps\common\assettocorsa). Its files are read on this computer by this page only; nothing is uploaded and nothing is changed.

      The display shows the levels all the time (TC 2/3, ABS off,
      Bias 58.0 %); a level goes up to its highest and then to off. Back does its
      own job when you let it go, and none at all if you used the D-pad while holding it.
      Left Shift is also the clutch: use Right Shift for Shift+T and Shift+Y while moving.
    
    
    
    
      These are Assetto Corsa's default keys plus WASD. AC keeps your own bindings in
      Documents\Assetto Corsa\cfg\controls.ini, which is not inside the game's folder,
      so the page cannot read it: the defaults stand.
