Controls

Your own file is Documents\Assetto Corsa\cfg\controls.ini. It is read on this computer by the parser the desktop build uses: its steering numbers, its keys and its pad buttons all count. Nothing is uploaded; the settings are kept in this browser. A change works at once, also while you drive. The defaults are the built-in layout: AC's default keys, and the pad numbers this page has always used.

rustyAC browser preview

Assetto Corsa's physics, rewritten in Rust and compiled to WebAssembly: the same numbers, bit for bit, as the desktop build. A small picture, keyboard and gamepad. No sound, and not AC's own look: this is a preview.

1. Content

Chrome refuses folders under Program Files: use this instead. The browser asks whether to "upload" the folder's files: nothing is uploaded, the page reads them on this computer. It has to be picked again on every visit.

The folder is the one with content and system in it (...\steamapps\common\assettocorsa). Its files are read on this computer by this page only; nothing is uploaded and nothing is changed.

    Multiplayer
    
    
    
      Race on a real Assetto Corsa server (Kunos' own acServer) against other
      browsers, desktop rustyAC and Assetto Corsa itself. The server decides the track and
      gives you one of its cars, so that track and every car on the server have to be in the
      content above. Your name and a random player id are kept in this browser.

      The display shows the levels all the time (TC 2/3, ABS off,
      Bias 58.0 %); a level goes up to its highest and then to off. Back does its
      own job when you let it go, and none at all if you used the D-pad while holding it.
      Left Shift is also the clutch: use Right Shift for Shift+T and Shift+Y while moving.
    
    
    
    
      These are the built-in layout's keys: Assetto Corsa's default keys plus WASD. AC keeps
      your own bindings in Documents\Assetto Corsa\cfg\controls.ini, which is not
      inside the game's folder: load it under Controls above and its keys and pad buttons
      take the place of this table's driving rows (the Controls panel then lists them).
