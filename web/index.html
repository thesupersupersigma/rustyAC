rustyAC

Left out of the browser's sound: AC's two DSP plug-ins and the track's walls that muffle sound (occluders).

Your own file is Documents\Assetto Corsa\cfg\controls.ini. It is read on this computer by the parser the desktop build uses: its steering numbers, its keys and its pad buttons all count. Nothing is uploaded; the settings are kept in this browser. A change works at once, also while you drive. The defaults are the built-in layout: AC's default keys, and the pad numbers this page has always used.

While you drive every key is the game's: the browser's own (Alt+Left, Backspace, F5, F3, Ctrl+R, Ctrl+F, Ctrl+P, Ctrl+S, the mouse's back and forward buttons) do nothing, and leaving the page asks first. F12 stays the browser's. The browser keeps a few keys whatever a page does (Ctrl+W, Ctrl+T, Ctrl+N): press Full screen at the top of this tab and those are the game's too while you drive: Esc opens AC's ESC menu there as well, and holding Esc leaves full screen.

Graphics

A preset writes its settings into the page's own Documents\Assetto Corsa\cfg\video.ini; Settings' Video tab shows and changes the same file key by key (a preset that no longer matches it reads Custom). Full mode reads it as rustyac.exe does, when a drive starts: a change counts from the next drive. Render scale is rustyAC's own and counts at once. What the Video tab marks "not used" is kept in the file, but neither rustyac.exe nor this page draws anything different for it yet.

Controls

Downloaded data

What is cleared is downloaded again when a drive needs it. "Clear all" leaves your own launcher settings (the last row) alone: tick that row to clear them.

Diagnostics

The page's own log of the last few visits (connections, joins, downloads, errors), for a bug report. Nothing is sent anywhere.

rustyAC browser preview

Assetto Corsa's physics, rewritten in Rust and compiled to WebAssembly: the same numbers, bit for bit, as the desktop build. A small picture, keyboard and gamepad. No sound, and not AC's own look: this is a preview.

1. Content

Chrome refuses folders under Program Files: use this instead. The browser asks whether to "upload" the folder's files: nothing is uploaded, the page reads them on this computer. It has to be picked again on every visit.

The folder is the one with content and system in it (...\steamapps\common\assettocorsa). Its files are read on this computer by this page only; nothing is uploaded and nothing is changed.

    Multiplayer
    
    
    
      Race on a real Assetto Corsa server (Kunos' own acServer) against other
      browsers, desktop rustyAC and Assetto Corsa itself. The server decides the track and
      gives you one of its cars, so that track and every car on the server have to be in the
      content above. Your name and a random player id are kept in this browser.
